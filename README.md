# Blog Musical 🎵

Este proyecto es un sitio web dedicado a la música y a los artistas que han dejado huella en diferentes generaciones.

La idea nació con el propósito de crear un espacio sencillo y visual en el que las personas puedan conocer un poco más sobre géneros como el pop, el rock y la música urbana, además de algunos de sus artistas más representativos.

## ¿Qué encontrarás en el sitio?

En la página de inicio se presentan diferentes artistas, junto con una breve descripción y algunas de sus canciones más conocidas.

También contamos con una sección llamada **Nosotros**, en la que explicamos la historia del blog, nuestro objetivo y lo que buscamos transmitir a través de este proyecto.

Por último, el sitio incluye una sección de contacto para facilitar la comunicación con los visitantes.

## Secciones principales

- **Inicio:** muestra los géneros musicales y artistas destacados.
- **Nosotros:** cuenta quiénes somos y cuál es la esencia del blog.
- **Contacto:** permite que los usuarios se comuniquen con el equipo.

## Tecnologías utilizadas

Para desarrollar el proyecto utilizamos:

- HTML
- CSS
- Bootstrap
- JavaScript
- Git y GitHub

## Diseño

Elegimos una combinación de colores oscuros con detalles en naranja para darle al sitio una apariencia moderna y relacionada con el ambiente musical.

También utilizamos tarjetas, imágenes, botones para hacer que la navegación sea más dinámica y agradable.
